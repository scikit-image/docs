scikit-image 2.7.0rc0#

We’re happy to announce the release of scikit-image 2.7.0rc0!

New Features#

  • Add a warning when importing experimental skimage2 (#7873).

  • In skimage.feature, add a new parameter prescale to the functions blob_doh, blob_dog``, and blob_log. This parameter controls the internal rescaling behavior which makes it easier to set the threshold parameter correctly (#7858).

API Changes#

  • In skimage.io, remove imshow, imshow_collection, and show. This completes their deprecation. Instead, we recommend using matplotlib, napari, etc. for visualization (#7994).

  • In skimage.feature, deprecate the parameter threshold_rel in blob_doh, blob_dog``, and blob_log. The behavior of the parameters effects were difficult to reason about. Instead, use threshold in conjunction with the new parameter prescale (#7858).

  • In skimage.feature.peak_local_max, use None as the new default for the parameters num_peaks and num_peaks_per_label – the default behavior is the same as before but passing numpy.inf is deprecated (#8039).

Enhancements#

  • In skimage.measure.ransac, add the new optional parameter model_kwargs, which allows forwarding keyword parameters to the model’s from_estimate method. RansacModelProtocol has been updated accordingly (#8015).

  • In skimage.feature.peak_local_max, support passing floats to the parameter min_distance (#8039).

Bug Fixes#

  • In skimage.morphology, fix an unintended change in deprecated behavior in remove_small_objects and remove_small_holes. The deprecation of the parameters min_size and area_threshold introduced an off-by-one error when using them (#8003).

  • Don’t override users test selection with spin test (#7889).

  • In skimage.util.map_array, allow read-only arrays (WRITEABLE flag set to False) as input to the parameters input_arr, input_vals, and output_vals (#7535).

  • Ensure skimage.feature.peak_local_max returns results with the correct shape when no peaks where found and labels where given (#8039).

  • Undo (double) mirroring in ski2.morphology.dilation (#8060).

  • Unwrap seed refactor (#8142).

  • Fix structural_similarity win_size / gaussian_weights conflict (#8162).

  • In skimage.feature.corner_peaks, return peaks in intensity order when using labels and num_peaks as promised (#8167).

  • Honor NumPy’s copy semantics in the __array__ implementations for geometric transforms and ArrayMap (#8279).
